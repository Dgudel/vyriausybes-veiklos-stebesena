Is Lithuania doing better?

Six policy areas and {{ (pagr_sk + kitu_sk)|rodikliu }}, updated automatically: each area shows the key indicators ({{ pagr_sk }} in total), and another {{ kitu_sk }} are listed under “Other indicators”. Indicators are assessed using a predefined rule: improving, stable or worsening{% if bendra.info %} (a few whose direction is in itself neither good nor bad are only monitored){% endif %}. Click an indicator to see its charts, definition and sources.

How is it assessed? The latest value is compared with the same period a year earlier: monthly data with the same month of the previous year, quarterly data with the same quarter, annual data with the previous year. This avoids seasonal swings. A change smaller than the threshold set for the indicator counts as stable. All assessment rules →

Ar Lietuvai sekasi geriau?

Šešios politikos sritys ir {{ (pagr_sk + kitu_sk)|rodikliu }}, kurie atnaujinami automatiškai: kiekvienoje srityje rodomi svarbiausi ({{ pagr_sk }} iš viso), o dar {{ kitu_sk }} – skiltyse „Kiti rodikliai“. Rodikliai vertinami pagal iš anksto nustatytą taisyklę: gerėja, stabilu arba prastėja{% if bendra.info %} (keli, kurių kryptis savaime nėra nei gera, nei bloga, tik stebimi){% endif %}. Paspaudę rodiklį pamatysite grafikus, apibrėžimą ir šaltinius.

Kaip vertinama? Naujausia reikšmė lyginama su tuo pačiu laikotarpiu prieš metus: mėnesiniai duomenys – su tuo pačiu praėjusių metų mėnesiu, ketvirtiniai – su tuo pačiu ketvirčiu, metiniai – su ankstesniais metais. Taip išvengiama sezoninių svyravimų. Pokytis, mažesnis už rodikliui nustatytą slenkstį, laikomas stabiliu. Visos vertinimo taisyklės →
